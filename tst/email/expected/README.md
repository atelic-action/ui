# Frozen jq Goldens

Every file here was generated by running homebase `runners/lib/email.jq` at commit `2b04a5a3`, the jq library `src/email/` was ported from, with synthetic arguments. The names and numbers are invented; nothing here came from a runner's real output.

Regenerating one against a newer jq would defeat the point. These are frozen: they say what the email looked like the day the port was made, and a component that stops matching one has drifted from the design, not from the fixture. Changing the design means changing both sides deliberately.

The `.html` files are compared after DOM normalization (`../normalize.ts`), never byte for byte: React writes `&#x27;` where jq writes `&#39;`, `<br/>` where jq writes `<br>`, and an explicit `<tbody>` where jq leaves the parser to insert one. The `text/` files are compared byte for byte, because a column that drifts by a space is the failure the plain text part exists to prevent.

The generating command, for the record:

```bash
jq -rn -L <homebase>/runners/lib 'include "email"; <call>'
```
