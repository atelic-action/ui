# Findings: Primitives, Components, and Artifact

The bugs the stories of the primitives, the components, and the artifact pieces exposed (`stories/primitives/`, `stories/components/`, `stories/artifact/`), each fixed in `src/` by a later pass. Written only by that group's writer; the format is in `stories/README.md`. Ratios are on the stories' theme, the practice's palette in `.storybook/theme.css` (`--primary` `#fc4a1a`, `--primary-fill` `#d63a10`, `--primary-ink` `#b8300b`, on `--surface` `#f6f1e7` and `--card` `#fdfbf6`, with `--neutral-500` `#8a8272`), measured after 8.0.0's fill and ink tokens. Widths are the page's `scrollWidth` against the pinned viewport.

## Accessibility

- `section-heading-on-dark-lead`: `SectionHeading` (OnDark). Rule `color-contrast`. `onDark` lifts the eyebrow only; the lead keeps `.lead`'s `--ink-soft`, 2.26:1 (`#55503f` on `#151515`) at 20.8px. The title is saved only by inheriting the band's color, which a site with a colored `h2` loses.
- `muted-text-contrast`: every quiet caption in `--neutral-500` on the surface or the card, 3.38:1 on `--surface` and 3.68:1 on `--card`, at 10 to 20px. Rule `color-contrast`. Hit in `StatRow` (the earlier figure, the basis, a muted change, the period, the denominator, the unit, the note, the quiet row's label), `Disclosure` (the controlled card's `meta`), `GateLogin` (`.gate-fine`), `ColumnChart` (the group labels), `ThresholdScale` (the tick labels), `ReportCard` (the card's title), and `Shot` (the caption). The README documents `--neutral-500` as the token for captions, so the token itself is under the floor on this palette. A theme change moving the practice's quiet gray from `#8a8272` to `#736c5f` is pending on another branch and should close most of this; the markers stay until both branches are on main.
- `tone-good-text-contrast`: `StatRow` (a good change or delta, every story showing one) and `ThresholdScale` (a good reading's figure and the "Good" zone label). Rule `color-contrast`. The package's own `--tone-good` (`#1b7f3b`, a default in `styles/defaults.css`, not the theme) on the surface is 4.49:1, a hair under 4.5:1, at 12 to 17px bold. A darker default (`#1a7a39`, 4.8:1) fixes every site at once.
- `gate-fine-link-distinct`: `GateLogin` (every story showing the contact address). Rule `link-in-text-block`. The fine print's mail link, now `--primary-ink`, still differs from the quiet words around it by color alone, 1.59:1 (`#b8300b` against `#8a8272`), with no underline. It needs an underline, or 3:1 against the words beside it.
- `star-rating-nested-buttons`: `StarRating` (EditableByKeyboard, EditableByPointer, EditableOnPhone). Rule `nested-interactive`. An editable row is `role="slider"` holding ten half star `<button>`s (`tabIndex={-1}`, but still focusable); a slider's children are presentational, so a screen reader may flatten or skip them. The keyboard path works; the pointer targets want to be plain elements (spans with pointer handlers) rather than buttons.
- `column-chart-empty-unnamed`: `ColumnChart` (Empty). Rule `role-img-alt`. With no bars the plot is still `role="img"`, with `aria-label=""`. It should say there is nothing to show, or not be an image.
- `error-fallback-message-unfocusable`: `ErrorFallback` (LongestOnPhone). Rule `scrollable-region-focusable`. In a development build the message box (`pre`, `overflow: auto`, `max-height: 160px`) scrolls, but has no `tabIndex`, so a keyboard cannot scroll it. Inline styled with no class, so the marker names the screen's one `pre`.

## Behavior

- `long-word-overflow`: `Lead`, `QuoteCard`, `SectionHeading`, `TickList`, `Eyebrow`, `Callout`, `Checklist`, `IconList`, `DataTable` (the stacked rows), and `Paragraph`, each in its LongestOnPhone story. A long unbroken word or a bare URL runs past a 390 phone and the page scrolls sideways: Lead 497, QuoteCard 574, SectionHeading 854, TickList 451, Eyebrow 490, Callout 568, Checklist 551, IconList 549, DataTable 524, Paragraph 523. The text these components set has no `overflow-wrap` (only `ProseBlocks`' body and list, `stat-figure`, and two rules in sections and chrome do), and several sit in flex items without `min-width: 0` (Component Rules 5). One fix in the base sheet (`overflow-wrap: anywhere` on text under `.atelic-ui`, or on each component's text) clears most of them.
- `chip-nowrap-overflow`: `Chip` (LongestOnPhone). `.chip` sets `white-space: nowrap`, so a long label never wraps: 506 at 390.
- `stat-figure-word-overflow`: `StatRow` (LongestOnPhone). A figure given as one long word (`value` is any node) runs to 920 at 390. `.stat-figure` sets `overflow-wrap: break-word`, which does not lower an inline flex item's minimum width; the sheet's comment promises the word breaks. `overflow-wrap: anywhere` does.
- `sign-off-address-nowrap`: `SignOff` (LongestOnPhone). `.op-who a` is `white-space: nowrap`, so a long address runs to 507 at 390.
- `data-table-no-scroll-box`: `DataTable` (WidestOnTablet). Thirteen columns at 820: the page scrolls to 1422. On a wide screen the table has no box that scrolls (`.data-table` sets no `overflow-x`), so a wide table widens the page instead of scrolling inside itself (Component Rules 5 and 6).
- `error-fallback-phone-overflow`: `ErrorFallback` (LongestOnPhone). In a development build, where the message shows, a long message runs the page to 405 at 390: the card is `max-width: 420` inside 24px padding, and the flex item holding it never shrinks below the `pre`. Production hides the message, so only a developer sees it.
- `column-chart-tone-color-only`: `ColumnChart` (MarkedBar). A bar given its own tone, keyed in the legend ("The month the order form was down"), is told by color alone: the plot's name carries every label and figure but never the tone or the legend's meaning, and the legend's swatches are hidden. The group label and total do reach the name, so a chart whose tones only mark groups is fine.
- `threshold-zone-not-spoken`: `ThresholdScale` (ZoneIsSpoken). Each track's name is "Home page: 4.1 s"; the zone it falls in ("Poor") is not spoken, and the zone labels and tick lines are `aria-hidden`, so the verdict the scale exists to show reaches a screen reader only as the pin's position and color. The name should carry the zone (it is computable from `zones` and `value`).
- `not-found-arrow-in-name`: `NotFound` (ArrowIsDecoration). The closing action's arrow is a bare `<span className="arrow">` without `aria-hidden`, so the link is named "Order ahead →". `Button` hides its arrow; `NotFound` renders its own markup and does not.

## Observed, Not Yet Marked

- `ProseBlocks`: `.pb-body`, `.pb-list`, and `.pb-lightbox-caption` read `--neutral-700`, a token no sheet defaults, the theme contract does not list, and the stories' theme does not set. The color falls back to inheritance, so it reads as the ink, harmless on this theme, but a site setting a pale `--neutral-700` for something else would gray its prose.
- `ProseBlocks` lightbox: closing drops the dialog's `open` at once, but its `close` event arrives a task later, and the handler sets the lightbox closed whatever its state is then. A reopen inside that task is closed again. No reader is that fast, so it is a race only a test can hit; each way out now has its own story, so none reopens. A handler that ignores a close while the dialog is open again would remove it.
- `SignOff`: `.op-sign` reads `--font-script`, which nothing defines here or in the theme contract; the script line falls back to the body font. Documents in `@atelic-action/artifact` may set it; on its own the sign off has no script.
- `ImageFrame`: `.imgframe` reads `--shadow-md` (and `.is-lifted` `--shadow-lg`) with no fallback and no package default; the stories' theme sets only `--shadow-sm`, so the frame draws no shadow. The hint bubble and the chrome give the same token a fallback; the frame does not.
- `StarRow`: a rating rounds, so 4.5 draws and announces "5 out of 5 stars" (HalfRoundsUp), and 0 clamps to one star (ClampsLow). Both are documented, but the first overstates a real rating, which is what the component's own comment warns against.
- `Disclosure`: a closed controlled card's `aria-controls` names a panel that is not in the page (the body is unmounted while closed). axe allows it when `aria-expanded="false"`, so nothing fails, but assistive tech following the relation finds nothing.

## Checker Limits

- `checker-watermark-tiles`: `Watermark` (Tiled). The tiled layer is faint on purpose (1.07:1, `#f6e7db` on the surface) and `aria-hidden`, decoration WCAG exempts, but axe measures hidden text too. Not a bug; the marker lifts the rule off `.gate-wm-tile` alone.
- axe skips a single character (`shortTextContent`), so a one digit `Bubble` number is never measured; the stories use two.
- The test's `userEvent.tab()` does not know that a closed `<details>` or a panel `hidden="until-found"` hides its content, and tries to focus a link inside; the stories ask the browser instead (`link.focus()` and assert it did not take focus).
- The test's click dispatches the press and the focus in one task, so Radix Tabs' activation on press and again on focus can both run before React renders, and `onSelect` may report the first pick twice. A real click renders between the two; the Click story asserts no new call on the open tab instead of an exact count.
- A story's `tags` set inside a spread const is invisible to Storybook's indexer, which reads only a literal `tags` on the story, so neither `grep known-issue` nor the sidebar sees it. Every marked story in this group carries the tag literally; the parameters may still come from a const.
